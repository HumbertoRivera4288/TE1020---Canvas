# Atlas Eléctrico de México | SolarPro
Primera entrega de la etapa 4: página principal, navegación y estilos visuales responsivos.

## Publicar en GitHub Pages
1. Sube `index.html` a la raíz de un repositorio.
2. Abre **Settings → Pages**.
3. Selecciona **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guarda los cambios y espera la publicación.

## Alcance de esta entrega
- Identidad visual SolarPro y paleta naranja/solar.
- Portada con el título y subtítulo del proyecto.
- Navegación en el orden correcto: módulos 0, 1, 2, 3 y 4.
- Diseño adaptable a móvil y escritorio.
- El contenido interactivo de cada módulo se implementará en las siguientes entregas.
- La tipografía Manrope/DM Sans se carga desde Google Fonts; hay fuentes alternativas si no hay conexión.
